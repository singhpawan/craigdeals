When you're setting up a Snowflake storage integration for Azure and need to define the `STORAGE_ALLOWED_LOCATIONS`, you're essentially telling Snowflake which Azure storage containers it's permitted to access. Here's how to find the container information:

**1. Azure Portal Navigation:**

* **Go to your Azure Storage Account:**
    * Log in to the Azure portal.
    * Navigate to your storage account.
* **Locate the Containers:**
    * In the storage account's overview, find the "Containers" section.
    * Here, you'll see a list of your storage containers.
* **Get the Container Name:**
    * The name displayed in the "Containers" list is the container name you'll use in your Snowflake storage integration.
* **Construct the Storage Location URL:**
    * To use the container in the `STORAGE_ALLOWED_LOCATIONS` parameter, you'll need to construct a URL with the following format:
        * `azure://<storage_account_name>.blob.core.windows.net/<container_name>/<optional_path>/`
        * Replace `<storage_account_name>` with the name of your Azure storage account.
        * Replace `<container_name>` with the name of the container you want to allow.
        * `<optional_path>` is used if you want to restrict access to a specific folder within the container. If you want to allow access to the entire container, you can omit this.

**Example:**

* If your storage account name is `mydataaccount` and your container name is `rawdata`, the `STORAGE_ALLOWED_LOCATIONS` value would be:
    * `azure://mydataaccount.blob.core.windows.net/rawdata/`
* If you wanted to only allow access to a folder named "csvfiles" within the rawdata container, the value would be.
    * `azure://mydataaccount.blob.core.windows.net/rawdata/csvfiles/`

**Key Points:**

* **Tenant ID:** Remember that you'll also need your Azure tenant ID when creating the Snowflake storage integration.
* **Permissions:** Ensure that the Snowflake service principal has the necessary permissions (e.g., "Storage Blob Data Reader") to access the specified containers.
* **Snowflake Documentation:** Always refer to the official Snowflake documentation for the most accurate and up-to-date information.

By following these steps, you can accurately identify and use your Azure storage container locations in your Snowflake storage integration.
