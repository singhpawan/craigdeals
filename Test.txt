Using Snowflake JDBC/ODBC Drivers with Custom Scripts (e.g., Python, PowerShell)

How it Works: Write a custom script that:
Connects to your Snowflake reader account using its JDBC/ODBC driver and your reader account credentials.
Executes a SQL query to retrieve the data.
Processes the result set.
Uses Azure SDKs (e.g., azure-storage-blob for Python) to write the data to Azure Blob Storage or ADLS Gen2. Authentication to Azure Storage from your script would use connection strings, SAS tokens, or service principals.
Example (Conceptual Python with Snowflake and Azure SDKs):

import snowflake.connector
from azure.storage.blob import BlobServiceClient

# Snowflake Connection
conn = snowflake.connector.connect(
    user='your_reader_user',
    password='your_reader_password',
    account='your_reader_account_locator_or_url', # e.g., xy12345.east-us-2.azure
    warehouse='your_reader_warehouse',
    database='shared_db_name',
    schema='shared_schema_name'
)
cursor = conn.cursor()
cursor.execute("SELECT * FROM your_shared_table")
results = cursor.fetchall() # Or fetch in chunks

# Convert results to desired format (e.g., CSV string, Parquet bytes)
# For simplicity, let's assume a CSV string
csv_data = "\n".join([",".join(map(str, row)) for row in results])

# Azure Storage Connection
AZURE_STORAGE_CONNECTION_STRING = "your_azure_storage_connection_string_or_sas_details"
blob_service_client = BlobServiceClient.from_connection_string(AZURE_STORAGE_CONNECTION_STRING)
blob_client = blob_service_client.get_blob_client(container="yourcontainer", blob="path_to_export/mydata.csv")

blob_client.upload_blob(csv_data, overwrite=True)

cursor.close()
conn.close()





Using COPY INTO <location> with a SAS Token to Azure Blob Storage / ADLS Gen2

How it Works: You'll execute the COPY INTO <location> command in your Snowflake reader account, pointing directly to your Azure storage container and providing a SAS token for authentication.
Steps & Configuration:
Generate a SAS Token in Azure:
Navigate to your Azure Storage Account in the Azure portal.
Go to "Shared access signature" under "Security + networking."
Define permissions (at a minimum: Read, Write, List for the service, container, or object level as appropriate for unloading files). Create might also be needed if files/directories don't exist.
Set an appropriate start and expiry time for the token.
Generate the SAS token and connection string. You'll primarily need the Blob service SAS URL or the SAS token itself.

Ensure yourstorageaccount, yourcontainer, and path_to_export match your Azure setup.
The AZURE_SAS_TOKEN should be just the token string (often starting after a ? in a full SAS URL).


Execute COPY INTO <location> in Snowflake:
COPY INTO 'azure://yourstorageaccount.blob.core.windows.net/yourcontainer/path_to_export/'
FROM your_database.your_schema.your_shared_table
CREDENTIALS = (AZURE_SAS_TOKEN = 'your_generated_sas_token_here_excluding_the_question_mark_if_part_of_full_url')
FILE_FORMAT = (TYPE = 'PARQUET' COMPRESSION = 'SNAPPY') -- Or CSV, JSON, etc.
-- Optional: MAX_FILE_SIZE, SINGLE, OVERWRITE, HEADER, etc.
;
